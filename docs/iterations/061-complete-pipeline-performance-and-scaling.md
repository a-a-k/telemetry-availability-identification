11 сентября 2026 года. По прямому запросу автора выполнено дополнение по производительности к [научному отчёту](../milestones/V3_MAIN_SCIENTIFIC_RESULT.md): [полный парный конвейер и масштабирование телеметрии](../milestones/V3_PIPELINE_PERFORMANCE_RESULT.md), run `34558252086`, и [размер модели/неполнота наблюдений](../milestones/V3_MODEL_SCALING_RESULT.md), run `34556966879`.
