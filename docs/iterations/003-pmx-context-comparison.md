# Итерация 003: независимый PMX с наблюдаемым контекстом

Вопрос и ожидаемый результат заданы до запуска в [M9X protocol](../M9X_PMX_CONTEXT_COMPARISON_PROTOCOL.md): устранит ли полный наблюдаемый caller path ложную рекурсию PMX при сохранении каждого native наблюдения? Нужны численные контроли, удержание исходного отрицательного случая и все 12 прикладных прогнозов/причин отсутствия.

Результат: [полный отчёт](../milestones/M9X_INDEPENDENT_PMX_DEVELOPMENT_COMPARISON.md), [таблицы](../evidence/m9x-34196680992/tables.md), run 34196680992 / head 4dac3acf0115ca7b532dcce02ebc325eceee9c10. Все 12 inclusive, шесть conditional-local, шесть честных conditional abstentions; 8 положительных oracle passes, две ожидаемые отрицательные ошибки, все 46 records. Аудит всех 11 архивов run 34198100749. Эта итерация завершена; новая основная серия не выполнена.

Старый inclusive результат из первоначальной модели не заменён без истории: обе прежние неудачные реализации и исходные результаты сохранены. Следующее действие — квалификация Petclinic runtime/семантики, затем общий новый протокол.
