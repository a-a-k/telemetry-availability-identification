# Four focused additions to the same five-step experiment

This amendment records the author's additions while original R experiment
34750418515 was running, before computing the new R forecast-error summaries.
The original R rules, binding, masks, five-step protocol and 18 saved campaigns
remain unchanged. The scientific question is necessary detail and its effect on
cost and result quality; external-comparator efficiency was tested previously.

## E control and consistent timing

Retain the initial three-route result with its own source identity. Run one
matched four-route grid, all on the same runner per application: full -> E,
full -> R, full -> projection -> R, direct -> R. The E query uses the existing
specialized completion-extrema algorithm restricted to the E target; it does not
compute additional target estimates or oracle certificates inside the timer.
Its result must match the frozen full model's original E solve after all timings.
The three R targets must agree, but E versus R is a different-target comparison
accompanied by the separate event, bounds and forecast analysis.

All four routes use the same inputs, warm file cache, fresh process, first-answer
clock, CPU/RSS boundary and subsequent 31 ready queries as the original protocol.
Use the same first split/N/0 calibration cases, 1/2/4 input volumes and three
rounds; rotate the four-route order with (round+volume_index) modulo 4.
There are 108 timed processes. Repeating the three R routes in this one grid is
required for a matched E control; it adds no observations or external tool runs.

## Nonoverlapping stages and sizes

Record JSON reading/decoding, native evidence interpretation, representation
construction, category-frequency identification, explicit reduction, target query
and serialization. Interpretation times wrap the unchanged native parser,
completion/admission/probe interpretation helpers in a private constructor scope.
These helper calls do not overlap each other: their internal calls use the
unchanged original globals. Category identification is a separate timed call.
The remainder of constructor time is representation/observation-row construction,
including dispatch/bookkeeping. Instrumentation applies symmetrically and its
model output must exactly match the original uninstrumented construction.
Keep per-operation stages/call counts, processed attempts/native span records,
variable counts and joint-category counts. A smaller representation does not
predetermine smaller first-answer costs.

## Retrospective forecast quality

R forecasts come only from the calibration part of fixed R run 34750418515,
source 934f177504aee378dd77ae0b593ec879f019d3e4. E forecasts must reproduce the
already frozen Gstar calibration forecasts. Test success/attempt counts come
from the verified full old forecast census in the repository, using the B0 rows
only as a complete carrier of the common observed test counts, not as a new fit.
Lock the exact census file hash. Check identities, periods and full 60-cell census.

Use the unchanged cell_metrics and own_metrics routines: MAE in percentage
points, signed error and Brier, equal operation/condition aggregation. Compare
E/R on common point support and separately retain own support, point/interval/
structural-refusal census and exact interval endpoints. Midpoints are not forecasts.
The original paired_primary campaign-cluster routine is reused with an explicit
R-for-left-target adapter and E comparator, preserving the original conditional
common-support rules, 10,000 draws, 0.05/6 tail allocation and seeds
771602/771604/771606 for the three applications in the original order.
No finite-sample family-coverage or statistical-equivalence guarantee is added.
If all common point probabilities are exactly equal as fractions, report direct
preservation of their errors rather than making an inference from a nonsignificant
contrast. Broader or different support is still reported separately.

This is retrospective saved-data analysis. R binding/rules were committed before
these aggregate errors, but the source test outcomes had already been opened.
No forecast differences may silently change the binding or group declarations.

## Boundary of the resulting claim

Never multiply new E/R or full/direct ratios by the earlier 31.73–100.24 Palladio
ratios. The older graph route computed multiple variants and had its own boundary.
Keep the two findings separate: external practical efficiency of the studied
graph method, and the detail/cost/quality tradeoff within this additional study.
No new traces or external-comparator experiments are authorized by this amendment.
