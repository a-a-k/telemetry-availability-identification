# Первый результат доработки: разбор отдельных попыток

**В первых 12 кампаниях локализованы 216 противоречащих попыток: сохранённая модель исключает зарегистрированный внешний успех при отрицательном прежнем verdict HAProxy.** Противоречий из-за явно ложного завершения или дедлайна в этой части совокупности нет. Это результат исторического аудита, а не независимое подтверждение исправленной модели; полная проверка 240 кампаний продолжается.

Сохраняется основной вклад: **формализация стохастической модели успешности операций, аналитическое исследование её свойств и границ применимости, автоматическое построение и идентификация по телеметрии**. Результат ниже проверяет применимость привязки наблюдений к этой модели.

Источник — [удалённый аудит 34694957306](https://github.com/a-a-k/telemetry-availability-identification/actions/runs/34694957306), код `02f31dc45efb05006117793fcd0fe770f49e9d1e`; первичная серия `34465226083`. [Протокол](V3_ATTEMPT_AUDIT_V1_PROTOCOL.md) и порядок всех 240 кампаний сохранены до запуска аудита. Первые четыре кампании каждого приложения выбирались для диагностики наибольших расхождений и сопоставимых условий N; это не случайная выборка и не оценка распространённости во всём исследовании. N — обозначение исходного закона отказов, а не отсутствие отказов.

Во всех 42 000 поддерживаемых попытках проверены оба направления `lower_i <= Y_i <= upper_i`. Во всех 37 123 полностью наблюдаемых попытках дополнительно непосредственно вычислен предикат. Противоположных ошибок и взаимного погашения в этой части не обнаружено; тест на искусственных записях подтверждает, что аудитор их выявляет. Совместимость агрегата не использовалась как замена проверке попыток.

Все 216 противоречий имеют хотя бы одну отрицательную probe coordinate, необходимую в исходном предикате. Признаки «выбрана отрицательная реплика» и «обе пробы отрицательны» пересекаются; их числа не складываются как независимые причины. В рассматриваемом DS `compose_post` сумма по попыткам воспроизводит L=925/1200, U=1001/1200 и B0=1057/1200: разрыв **56/1200 = 4,667 п.п.** здесь точно равен числу исключённых успехов.

## Что определено для продолжения

Первое обоснованное направление исправления — наблюдательное и временное соответствие eligibility. Простой переход 97 → 39 в агрегатной абляции ещё не задаёт окончательную модель. До выбора её новой версии нужны полный census, проверка внешних свидетельств и разбор переходов здоровья относительно фактических вызовов. Прежние доказательства остаются утверждениями о прежнем предикате; применимость к новому предикату проверяется отдельно. Исправленное преимущество по точности, новая подтверждающая серия и эксперимент с пропусками этим отчётом не объявляются выполненными. Историческое C12 сохраняется.
