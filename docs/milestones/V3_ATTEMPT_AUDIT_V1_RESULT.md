## Что определено для продолжения

Дополнительный [первичный аудит 34695678140](https://github.com/a-a-k/telemetry-availability-identification/actions/runs/34695678140), source `29f7fbd14cca526d4cc93da60180a644014769b5`, завершён на **всех 43 200 записях** этих 12 кампаний. Независимо реализованные приёмочные функции воспроизвели **39 831** внешний исход, без расхождений: все 28 800 DS/OTel исходов по исходным байтам обязательных HTTP-шагов и дедлайну, 10 800 Petclinic read-исходов по parsed payload и fixture из закреплённого SQL, а также 231 отказ записи по невыполненным необходимым условиям. Оставшиеся **3369** своевременных Petclinic write acknowledgments проверены по ответу, но исходные строки контрольного SELECT после записи не были сохранены. Их persistence verdict независимо не воспроизведён. Эти записи не отброшены; ограничение отмечено явно.

Таким образом, из 216 противоречий **183** имеют независимо воспроизведённый внешний исход. Для 33 Petclinic write-противоречий проверено подтверждение ответа, но независимое доказательство эффекта записи отсутствует. Приёмочные функции не вычисляют ответ из E и не используют сохранённую semantic_success для решения. Общий счёт 216 относится к зарегистрированным исходам; не следует переименовывать его в 216 независимо подтверждённых бизнес-успехов.

Окно фиксировано: от двух секунд до пробы до завершения запроса. Эти описательные категории не доказывают отсутствие более раннего перехода и не различают все перекрывающиеся воздействия или повторное использование соединений.

Например, в Petclinic `colocated/N/r0`, попытка `000746-create_visit`, отрицательный snapshot b записан в **15:14:39.368318Z**, снятие pause подтверждено событием `calibration-individual_b-006` после выполнения команды в **15:14:39.483978Z**, запрос начат в **15:14:39.868460Z**, native SERVER span b начинается в **15:14:39.872427741Z** и заканчивается HTTP 201. Здесь реплика успела восстановиться **до запроса**, а модель всё ещё подставила старое DOWN. В DS есть также освобождение сети **во время запроса**, до фактического native вызова. Это конкретные первичные свидетельства временного ограничения A3, а не предположение о неверно записанном proxy status.

Первое обоснованное направление исправления — наблюдательное и временное соответствие eligibility. Простой переход 97 → 39 в агрегатной абляции ещё не задаёт окончательную модель. До выбора её новой версии нужны полный census, проверка внешних свидетельств и разбор переходов здоровья относительно фактических вызовов. Прежние доказательства остаются утверждениями о прежнем предикате; применимость к новому предикату проверяется отдельно. Исправленное преимущество по точности, новая подтверждающая серия и эксперимент с пропусками этим отчётом не объявляются выполненными. Историческое C12 сохраняется.
