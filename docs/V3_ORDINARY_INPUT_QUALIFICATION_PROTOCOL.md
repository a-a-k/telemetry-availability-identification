# V3 ordinary input qualification: протокол до запуска

Вопрос: можно ли из сохранённых development acquisitions получить физически отдельный input role, который содержит calibration native/census и ordinary probes, исключает privileged Docker states и test-dependent metadata, и достаточно явно сохраняет структуру для следующего graph builder?

Объём: **два ранее полученных Petclinic NCD datasets**, colocated из run 34204098497/head `68bf0b86acab9072d0d8abfabb7c2d64d4a69546`, split из run 34202539028/head `06e83aad5f65f17365c7715ca3b312938b94f1a9`. Выбор по development данным. По 3600 calibration attempts, четыре операции по 900, calibration health/native из source role. Новые приложения, campaigns, fit, PMX solve и evaluator jobs = 0. Эти inputs не создают независимое новое n.

Два preparation jobs восстанавливают точный legacy learner, проверяя API size/SHA/ZIP CRC/source seal. Они являются trusted source-preparation role: могут читать старые privileged поля для проверки/проекции, их audit остаётся отдельным артефактом. **Downstream consumer** работает на новом runner и скачивает только `v3-ordinary-PLACEMENT-NCD-RUN`. Ему недоступны legacy bundle, preparation audit, fault schedules, test outcomes/health и прежний topology CSV.

Новый ordinary role имеет ровно пять JSON data files + seal: requests, probes, native, declarations, manifest. Requests — только calibration, все попытки, восемь явных внешних полей. Probes — только timestamp/elapsed и HAProxy backend_status/check_status для a/b. Native сохраняет IDs/time/kind/errors/links identities, semantic attributes из явного allowlist, service/replica metadata. Произвольные study.fault/Docker/runtime attributes, process/host metadata и link attributes не экспортируются; оригиналы остаются в remote source, discarded attribute keys считаются в preparation audit. Нативные SERVER/CLIENT/error/time не переопределяются. Declarations — явный static allowlist; source usability/test-health checks в manifest не копируются. Primary seal содержит только hashes нового ordinary содержимого, не скрытый feature из raw privileged bundle hash.

Источник ordinary probes получен старым общим collector Docker+HAProxy. Поэтому missingness нельзя объявлять независимой от состояния, и даже конечный UP/L7OK не объявляется прямым primitive-state наблюдением. Этот запуск проверяет передачу данных и графовую inventory, а не идентификацию θ или adequacy Φ. Для будущего acquisition обычный probe collector потребуется отделить от auditor inspection.

Consumer до любого input read включает process audit: разрешены ровно шесть ordinary files и library source; блокируются другие data reads/network/subprocess. Native inventory восстанавливает cross-service parent edges и отдельно явные DB CLIENT peer relations, считает supports/multiplicity/instances, missing parents/traces, raw probe statuses. Required business targets не выводятся автоматически; source-declared dependencies представлены отдельно. Output forecast=null со статусом `estimator_not_implemented_for_this_observation_law` — здесь ещё нет admitted estimator.

**Предварительные локальные контроли, только artificial:** пять unittest проверок — изменения privileged states/test-quality metadata не меняют primary data; изменения ordinary probes/outcome остаются видимыми; test periods/foreign native IDs отклоняются; privileged native tags удаляются при сохранении DB peer; отдельный процесс успешно читает шесть ordinary файлов и реально блокирует сторонний closed-test файл. No application data locally.

**Qualification gates:** exact source provenance/integrity; ordinary physical role exact schema/seal; по 3600 attempts и четыре operation inventories; legacy/test/schedule fields не переданы; actual consumer reads ровно шесть разрешённых файлов, blocked=[] в штатном запуске. Любое несоответствие даёт failure, исходный source не исправляется. Наличие/количество graph edges и отсутствие параметрического forecast публикуются как результаты, без gates на low error, topology completeness, unique θ или superiority.

**Ресурсы:** максимум два preparation и два consumer jobs, timeout 30 min каждого, без сборки/запуска приложений. Измеряется consumer elapsed/RSS и data bytes, GHA job durations сохраняются отдельно. Полные legacy/ordinary/native artifacts остаются удалённо. Локально/Git сохраняются только компактные preparation/consumer reports и источники с lock; retention 90 days, failure artifacts тоже сохраняются.

Frozen config: [v3_ordinary_input_qualification.json](../configs/v3_ordinary_input_qualification.json), source bytes проверяются [verifier](../scripts/verify_v3_ordinary_lock.py) до preparation/consumer. Workflow: [v3-ordinary-input-qualification.yml](../.github/workflows/v3-ordinary-input-qualification.yml). Следующий шаг после успеха — обоснованный estimator для выбранного compound observation law и фактически извлечённого G, с ambiguity/absence там, где target не идентифицируется. Applied G* chains до этого не увеличиваются.
