# Historical health prefix refit v1

Frozen before first execution. The complete [census](milestones/HEALTH_PREFIX_CENSUS.md) found changed calibration ticks in 119/160 M7 and 8/8 Petclinic cases, and changed test-health ticks in 117/160 M7. These opened development/historical data remain the same independent campaigns. PMX does not use the decoder and is not reexecuted for this correction.

This stage recomputes legacy and corrected predictions on the entire 160+8 cohort, including unaffected controls. M7 retains all four frozen observation modes, six methods, three operations per application, current and source-colocated→split transfer. Petclinic retains its two modes, six methods, four operations and source-colocated transfer. Expected slots per version: **17,280 M7 + 576 Petclinic = 17,856**, including every absence. B0 is the historical smoothed version, not B0-v3. These methods remain historical fixed-two-path models, not the new primary graph G*.

Only change: remove the documented `* ` prefix when decoding the last HAProxy result. All old parameters, seed derivation, request rows, health timestamps, primitive/runtime interpretation, transition guard, trace masking, topology qualification, likelihood, optimizer, identification tolerances, prediction formulas and status definitions remain the frozen historical versions. Parameter estimation uses the corrected joint rows and therefore its downstream guards/retained samples may change; those counts are reported. New outcome regression, new labels or new tuning are not introduced. No claim that privileged Docker inputs are eligible ordinary v3 inputs is made.

Trusted source preparation verifies nine exact retained archives and exports only six unmodified learner/qualification files and a new source seal per cell. It parses neither evaluator nor native members. Historical M7 YAML is converted to its existing `analysis` dataclass only in preparation; acquisition schedules/parameters are not in the builder settings. Petclinic reuses `isolated_stochastic_analysis.json`. Three fresh builder jobs receive only their learner artifact and analysis settings. An enforced process audit is active before source-seal verification, request/health loading, preparation and fitting, and permits only the current cell, settings and Python runtime/source. Every constructed cell has empty test fields. Transfer estimates cannot read another cell's calibration.

For a cell with identical old/corrected health tuples, compute the legacy fit once and reuse the exact result for the corrected version, with an explicit flag. Otherwise fit both versions using the same source/config/seed. This reuses computation, never adds independent observations. Retain all per-cell predictions, absences, fit/retained-sample diagnostics, actual read paths, stage time and hashes. Seal each candidate family before a separate comparison job downloads it.

The comparison job then reads the original historical prediction tables. Require identical identities and finite/absent patterns, identical statuses, and probability reproduction within **1e-6 absolute probability** for finite values. This is a numerical replay tolerance, not an accuracy, statistical significance or model-equivalence threshold. Preserve all mismatches and fail qualification if any occur; do not attribute a correction effect where legacy reproduction failed. Publish paired historical/legacy-rerun/corrected values and status changes for every slot. The original table is never overwritten. Tiny differences below tolerance are still retained, not rounded away.

Bounded tests compare the new calibration-only loader to the original loader for artificial M7/Petclinic cases, confirm that only health tuples differ after correction, and reject an extra evaluator file. Decoder/census tests from the earlier correction remain in force. Source/config locks use exact staged Git bytes and the pre-dispatch gate introduced after the two census preparation failures.

This first refit stage **does not score accuracy**. After parity and candidate seals, a separately frozen scoring stage must recompute the full M7 all-sequence/stable census, own/common coverage and dependent comparisons, separating prediction changes from changed stable-window membership. All-sequence outcomes themselves remain unchanged. Petclinic previously had technical fits, not an accuracy comparison to overwrite. Auxiliary historical diagnostic series require their own dependency scope before reuse. Main G* admission and scientific causal hypotheses are not closed by this correction.

Resources: one 15-minute preparation job, three builder jobs of at most 60 minutes, one 15-minute parity job; no benchmark acquisition, image build, native parsing or PMX solving. Artifacts retained for 90 days, including partial failed candidates. These are caps, not a power calculation. Locally execute only source/lock checks, compact aggregate inspection and artificial controls; complete inputs/refits stay on GitHub Actions.
