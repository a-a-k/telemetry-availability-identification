# Live qualification новой версии шести external contracts

Вопрос до запуска: соответствуют ли новые whole-operation predicates настоящим ответам pinned DeathStar/OTel и сохраняют ли полный внешний census/native linkage? Ожидаемый результат — по 240 paced baseline attempts (80 на операцию) и три semantic sentinels каждого приложения, нормальная доля success не ниже 95% для каждой операции, каждый success укладывается в общий deadline 2 s, successful trace linkage не ниже 95%. Invalid native records и любые неудачи сохраняются. Это проверка изменённого interface, не дополнительная stochastic effectiveness серия; fits/main campaigns=0.

Приложения, OCI locks и colocated two-replica deployment берутся из неизменных M7 configs. Новая версия [`publication_stochastic_live.py`](../src/telemetry_availability/publication_stochastic_live.py) импортирует прежние renewal/health/controller primitives и копирует ровно три orchestration functions без изменения их тела, чтобы связать новый driver без monkey patch исходного M7. [Derivation hashes](../configs/publication_acquisition_derivation.json) позволяют проверить это. `_execute_request` вызывает новый whole-operation contract, а raw responses.jsonl сохраняет все промежуточные HTTP payloads/IDs/offsets/deadlines. Historical CSV schema остаётся читаемой прежним evidence parser.

Run использует namespace ten-contract-qualification-RUN, workload seed 771501, 60 s и 4 RPS. Инъекций нет. Existing runtime fault/sampling/PMX controls M7/M9S/U/X и Petclinic controls остаются отдельными доказательствами. Проверка normal interface не объявляется доказательством идеального OR failover, отсутствия swallowed errors или полноты general graph. В частности TCP health двух прежних приложений сохраняет известное ограничение относительно paused processes; оно не исправляется скрытым изменением deployment.

При failure сохраняются compact diagnostic payloads и полный raw source на 90 days. Причина устанавливается до correction, original outcomes не заменяются. До прохождения этого interface check новая основная series не запускается. Exact HTTP predicates и границы claims находятся в [ten-contract table](TEN_EXTERNAL_OPERATION_CONTRACTS.md).
