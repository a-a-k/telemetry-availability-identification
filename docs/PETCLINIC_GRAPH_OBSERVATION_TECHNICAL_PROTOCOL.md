# Первый Petclinic graph build/replay: протокол до запуска

Метод `G-OBS-create-visit-technical-v1` проверяет **действительную** цепочку ordinary native/probes → G/R/observed law → Φ → saved-model replay. Это development технический пример одной операции, не окончательный G* и не основная сравнительная серия.

Данные: два ordinary NCD artifact из квалифицированного run 34212928736/head `b0ddadb83868e4a80b6a4391b9c65e2269012014`: colocated artifact 10050553358, 2,403,906 bytes, SHA `2961e5d2f9c34cc68fe458ec3dda07730e7888eae2056859dc2dda476c3e25de`; split 10050553448, 2,430,058 bytes, SHA `3583d1f0a2d8d6a74e7c9dd033e34c3182550804da18851c7fee9a0ca129859c`. Каждый содержит только пять ordinary JSON + seal. В новом job не скачиваются legacy learner, evaluator или fault schedules. Data already viewed/development; новое независимое n не возникает.

Выбрана create_visit: 900 calibration attempts/case, все 901 ordinary probe ticks без отбора по business success. Native граф восстанавливается из parent links и явно наблюдаемых DB CLIENT peers; required Visits + shared DB endpoint задаются pinned source/внешним contract. Проверяются trace ID `SHA256(request_id)[:32]` и каждый external native root parent `SHA256('client:'+request_id)[:16]` из неизменённого Petclinic contract. Только такой missing parent признаётся объявленной границей; другие дают qualification failure. Реплики связываются через `study.replica` и observed service.instance.id, не угадываются по порядку spans.

R: target-service replicas gated эффективными `probe_a/probe_b`; **остальные реально обнаруженные узлы остаются в графе**, но имеют явно объявленную детерминированную live reduction. Это не измеренная availability=1 и не установленная независимость Gateway/DB. Baseline q отсутствует. Edges трактуются как sync для pinned HTTP/JDBC create_visit execution; additional communication variables не оцениваются. Идеальное переключение и постоянство эффективного состояния за операцию — допущения. Их несоблюдение относится к adequacy/H-EXEC-01, не скрывается успешным численным gate.

P: эмпирический **совместный** закон ordinary eligibility signals с сохранением masks, без replica independence, Docker inspection, latent cause MLE или calibration outcome correction. HAProxy `* ` отделяет in-progress от последнего результата; raw strings не переписываются. Unknown сочетания дают missing coordinate. [I3](GRAPH_OBSERVATION_LAW_V3.md) вычисляет sharp plugin bounds по совместным категориям и Φ; null forecast при неоднозначности не заменяется нулём. Population identification/CI по конечной выборке не утверждаются. Future-state distribution stability — допущение, не измеренный факт.

Π вычисляется graph traversal каждого состояния; узлы/рёбра не используются только как decorative metadata. Saved JSON содержит graph, replica gates, operation, observed law, assumptions и ordinary source seal. **Отдельный replay job** получает только model artifact. Во время replay process разрешён только model.json (+ библиотечный код), ordinary/native данные не передаются. Auditor после обоих jobs сравнивает исходный и replay prediction/interval/model SHA. Graph mutation удаляет входящие рёбра обязательного DB node и должна дать 0; перестановка рёбер сохраняет весь результат. Это контроль фактического влияния графа, а не точности относительно приложений.

Gates: exact pinned ZIP/source seal; 900 external boundary roots/case и отсутствие иных unresolved parents; observed mappings обеих реплик/одного shared peer; six-file read audit у builder и one-file у replay; identical prediction/interval/model SHA; положительная верхняя исходная graph probability и нулевая после удаления обязательной связи (по ранее измеренным ordinary observations есть положительная масса eligible состояний). **Нет gate на observed application success, bias/MAE, superiority или уникальность физических причин.** Если unsupported, статус/ошибка и source artifacts сохраняются; основная серия не начинается.

Source-only transfer этой версии **не поддерживается**: arbitrary source joint law не определяет закон при изменении sharing/routing. I2 counterexample сохраняется как объяснение ограничения. Это явный remaining criterion, не разрешение использовать target calibration.

Расходы: 2 build + 2 replay + 1 compact qualification job, timeout 30/30/10 min, без новых приложений/campaigns и PMX solve. Измеряются build/replay elapsed и GNU time/RSS; full model/native archives остаются remote, локально только compact reports/audits. Все artifacts, включая failures, retention 90 days. Frozen [config](../configs/petclinic_graph_observation_technical.json) содержит hashes code/workflow/protocol до запуска.

Следующий научный этап после этого технического примера — оценить graph/observation adequacy на development outcomes, оформить допустимый класс и механизм; затем подготовить аналогичные примеры двух других приложений и зафиксировать G0/G-ID/G*, ablations и causal budget. Успех этого job не закрывает admission v3 автоматически.
